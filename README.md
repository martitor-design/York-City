# York Summer Portal

A Next.js website for York City, Pennsylvania summer programs, parks, events,
and resident resources.

## Run the site

From the repository root:

```bash
npm install
npm run dev
```

The dev script binds to `0.0.0.0:3000` for cloud previews. Then open the forwarded preview for port `3000`. In Cursor Cloud, use the Ports or Preview panel and open port `3000`.

## Other commands

```bash
npm run build
npm run typecheck
npm audit --omit=dev
```
